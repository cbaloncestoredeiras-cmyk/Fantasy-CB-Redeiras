# Despliegue (pendiente)

1. Crear proyecto Supabase en región europea.
2. Aplicar migraciones SQL revisadas, habilitar RLS y verificar permisos con cuentas de prueba.
3. Configurar autenticación por invitación y asignar el primer administrador desde un procedimiento seguro (no mediante correo visible en frontend).
4. Conectar GitHub a Cloudflare Pages. Elegir configuración de compilación correspondiente al frontend definitivo.
5. Configurar las variables de entorno públicas de Supabase; guardar las claves privadas únicamente en el servidor.
6. Probar registro, fichajes simultáneos, cierre del mercado, puntuaciones, votos, privacidad de menores, backups y recuperación.
7. Solo entonces activar la aplicación para participantes.

**No desplegar el prototipo HTML como aplicación de producción.**
